# QFlareBot 通用积分插件（Points）

为 QFlareBot 提供通用积分钱包，依赖 QFlareBot 宿主运行。支持用户开户、余额与流水查询、转账，以及其他插件共用积分。

## 功能

- 本金冻结、释放、到期处理与原子结算
- 发行、销毁、完整冲正及关联原交易的管理员补偿
- 按 SID 或已绑定 QQ 号查询账户和流水，手动导出整月流水
- 来源权限管理、转账手续费、Markdown 回复模板与消息按钮编辑

## 使用

1. 在 QFlareBot 中安装并启用插件，打开“积分管理”页面。
2. 用户私聊机器人发送 `/积分 开户`，开通本人账户。
3. 其他插件主动登记来源后，由管理员在“来源权限”中启用并授权。
4. 如需用户转账，在“转账设置”中开启；默认关闭，手续费默认免费。

| 私聊命令 | 用途 |
| --- | --- |
| `/积分` | 查看帮助及快捷按钮 |
| `/积分 开户` | 开通本人零余额账户 |
| `/积分 余额` | 查询可用与冻结积分 |
| `/积分 流水` | 查询本人当月流水 |
| `/积分 转账 SID 金额` | 向已开户用户转账，确认后执行 |

每个机器人使用一个共享钱包，积分保留两位小数。用户转账须在五分钟内确认，手续费统一销毁。账户只由 Points 本人开户命令创建，其他插件和管理员不代开。

## 其他插件接入

声明依赖 `depends: { 'points.wallet': '*' }`，通过 `ctx.service<PointsService>('points.wallet')` 调用；公开类型见 [src/contracts.ts](src/contracts.ts)。

新业务先查户，缺户时提示本人开户并停止。来源首次登记默认禁用，重复登记不覆盖已有权限。消费插件保存完整输入和稳定操作编号，结果不明时使用原编号查询或原参重试，避免重复发放或扣款。

资金流水和幂等结果保存在 D1，资金变动与流水原子提交。管理页面按需加载，打开页面和切换标签不自动查询业务数据。
